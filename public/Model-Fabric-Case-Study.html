Project Overview

Data exploration and statistical processing simplified.

Model Fabric 2.0 is an enterprise statistical and AI model training tool within the ABB Ability™ Genix Platform. It empowers citizen data scientists and process engineers to build, train, recommend, and rapidly deploy machine learning models directly at continuous production industrial plants without writing code.
